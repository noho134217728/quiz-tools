# 無機化学 化学反応式小テスト生成器

問題文から化学反応式を書き、化学反応の分類を記号で答える印刷用小テストを生成するツールです。

## ファイル構成

```text
chem-quiz/
  index.html
  reactions.csv
  reactions.json
  csv_to_json.py
  README.md
```

## 分類記号

| 記号 | 分類 |
|---|---|
| ア | 酸塩基反応：酸化物と水の反応 |
| イ | 酸塩基反応：中和反応 |
| ウ | 酸塩基反応：遊離反応 |
| エ | 酸化還元反応 |
| オ | 熱分解反応 |
| カ | 沈殿生成反応 |
| キ | 錯体生成反応 |

## CSVの書き方

`reactions.csv` は次の列を使います。

```csv
id,unit,chapter,statement,equation,categories,note,level
```

| 列 | 内容 |
|---|---|
| id | 問題ID。空欄でもよいが、管理上は入れるのがおすすめ。 |
| unit | 第I部、第II部など。任意。 |
| chapter | 中和反応、沈殿生成反応など。任意。 |
| statement | 問題文。 |
| equation | 解答となる化学反応式。 |
| categories | 分類記号。複数回答の場合は `イ;カ` のようにセミコロンで区切る。 |
| note | 解答欄に出す備考。任意。 |
| level | 難易度。任意。 |

例：

```csv
001,第I部,中和反応,二酸化炭素が水酸化ナトリウムに吸収される。,2NaOH + CO_2 -> Na_2CO_3 + H_2O,イ,酸性酸化物と塩基の中和,2
002,第II部,沈殿生成反応,硝酸銀水溶液に塩化ナトリウム水溶液を加える。,AgNO_3 + NaCl -> AgCl↓ + NaNO_3,カ,塩化銀の白色沈殿,1
003,第I部,中和・沈殿,石灰水に二酸化炭素を少量通じる。,Ca(OH)_2 + CO_2 -> CaCO_3↓ + H_2O,イ;カ,中和と沈殿生成が同時に起こる,2
```

化学式では、`H_2O` のように `_` を使うと画面上では下付き表示になります。`Fe^3+` や `OH^-` のように `^` を使うと上付き表示になります。

## JSONへの変換

CSVを編集したら、次を実行します。

```bash
python csv_to_json.py
```

または入力ファイルと出力ファイルを指定します。

```bash
python csv_to_json.py reactions.csv reactions.json
```

## 起動方法

ローカルで `fetch("reactions.json")` を使うため、フォルダ内で簡易サーバーを立てるのが確実です。

```bash
cd chem-quiz
python -m http.server 8000
```

ブラウザで次を開きます。

```text
http://localhost:8000
```

`index.html` を直接開いた場合、ブラウザの制限で `reactions.json` の自動読み込みに失敗することがあります。その場合は画面上の「データ読み込み」から `reactions.csv` または `reactions.json` を選択してください。

## 使い方

1. 分類を選択する。
2. 出題数を指定する。
3. 必要なら乱数シードを入れる。同じシードなら同じ並びになります。
4. 「小テストを生成」を押す。
5. 「印刷」を押す。

解答用紙も同時に生成できます。印刷時は設定画面が非表示になり、問題用紙と解答用紙だけが印刷されます。
